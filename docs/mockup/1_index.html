Kartu Tanda Penduduk (KTP)

Identitas resmi yang mencantumkan NIK yang valid.

Kartu Keluarga (KK)

Dokumen verifikasi data domisili dan keluarga.

Ijazah Terakhir

Ijazah pendidikan formal sesuai kualifikasi program.

Seleksi Administrasi & Wawancara

Pantau status seleksi secara realtime melalui dashboard akun Anda.

4
Pengumuman Kelulusan

Deskripsi Program

Program pelatihan ini dirancang untuk menyiapkan tenaga ahli di bidang pengembangan web. Materi meliputi Fundamental HTML/CSS, JavaScript Frameworks, Database Relational, dan Deployment Aplikasi.

Persyaratan Khusus
  • Warga Negara Indonesia (WNI), usia 18 - 35 tahun.
  • Pendidikan minimal SMA/SMK sederajat (Diutamakan jurusan Rekayasa Perangkat Lunak/Informatika).
  • Memiliki laptop/komputer pribadi dengan RAM minimal 8GB.
